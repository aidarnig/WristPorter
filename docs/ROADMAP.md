# Roadmap

This document defines only the **milestone sequence**. Actionable work and completion checks live in [GitHub Issues](https://github.com/aidarnig/watch-gallery-sync/issues).

| Milestone | Result |
| --- | --- |
| M0: Foundation | Maven modules, JavaFX + Spring Boot startup, change-aware CI |
| M1: Connection | Discover ADB, pair, select and connect to watches |
| M2: Import | Select files/folders, thumbnails and drag & drop |
| M3: Transfer | Batch copy, media scan, progress, retries and cancellation |
| M4: UX | Themes, RU/EN, preferences and accessible messaging |
| M5: QA | Simulated ADB tests, real-watch verification, Windows testing |
| M6: 1.0 | Signed/verified distributable, docs, tagged release |

Only a hardware-tested build can be called 1.0. Other Wear OS devices are best-effort until verified.
