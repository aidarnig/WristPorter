# Sharing WristPorter

These are short, factual starting points for sharing the project after the README is updated. Adapt to each community's rules; don't post the same text repeatedly or imply official manufacturer support.

## English — community introduction

**Title:** I built a Windows tool to send photos to my Galaxy Watch after switching to an iPhone

I moved from a Samsung phone to an iPhone and missed being able to send photos to my Galaxy Watch. So I made **WristPorter**, a free, open-source Windows app that sends JPG/PNG images over Wi-Fi using ADB.

It pairs with the watch from the app, transfers batches and requests Gallery indexing. The full workflow is tested on my **Galaxy Watch4 Classic**. Other Wear OS models may work, but they aren't verified yet. The watch must already be set up, and this doesn't connect a Galaxy Watch to an iPhone.

GitHub: https://github.com/aidarnig/WristPorter

If you have another Wear OS watch with wireless debugging, I'd be glad to hear whether both the transfer **and** Gallery display work for you.

## Русский — сообщение для сообщества

**Заголовок:** Сделал программу для отправки фотографий с Windows на Galaxy Watch после перехода на iPhone

После перехода со смартфона Samsung на iPhone я потерял привычную возможность отправлять фотографии на Galaxy Watch. Поэтому сделал **WristPorter** — бесплатную программу с открытым кодом для передачи JPG/PNG с Windows на часы по Wi-Fi через ADB.

В программе можно сопрячь часы, отправить сразу несколько снимков и обновить галерею. На моих **Galaxy Watch4 Classic** всё работает, включая появление фотографий в Samsung Gallery. На других Wear OS-часах это ещё не проверено. Часы уже должны быть настроены: WristPorter не подключает Galaxy Watch к iPhone.

GitHub: https://github.com/aidarnig/WristPorter

Если попробуете на других Wear OS-часах, буду рад результатам — отдельно по передаче и отображению фото в галерее.
