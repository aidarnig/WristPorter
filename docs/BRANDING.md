# WristPorter branding

This file is the single reference for **visual identity and social preview maintenance**.

## Approved identity

The brand uses a blue-to-cyan smartwatch mark with a **WP** monogram and photo symbol on its face. The Windows executable, taskbar and window icon use **only the watch mark**. The JavaFX header displays the full wordmark with a dark `Wrist` on light surfaces and a light `Wrist` on dark surfaces; `Porter` remains blue-to-cyan.

## Canonical and derived assets

- `docs/assets/watch-icon.svg` — standalone watch icon
- `docs/assets/logo-light.svg` / `logo-dark.svg` — full theme-aware wordmarks
- `docs/assets/social-preview.svg` — 2:1, 1280×640, central content with safe margins
- `docs/assets/ui-preview-ru.svg` / `ui-preview-en.svg` — **illustrations**, not actual screenshots
- PNG counterparts and `wristporter.ico` — generated by `ci/render-brand.py`

The `Generate branding assets` workflow regenerates and commits binary exports only when their SVG sources or generator change. The Windows portable packaging uses `docs/assets/wristporter.ico`.

## Set GitHub Social Preview

GitHub's repository Social Preview is not set by merely committing an image. The repository owner should verify this setting under **Settings → General → Social preview** and, if the preview is missing, use **Edit → Upload image** for the existing **[1280×640 social-preview.png](assets/social-preview.png)** file. This GitHub setting currently cannot be changed by the connected repository-content integration.

## Windows Explorer icon troubleshooting

The Windows package already embeds the branded blue WP watch icon in `WristPorter.exe`. The packaging test extracts the icon and confirms that it matches the expected art. If Explorer displays an older Java icon while the window and taskbar show WP, Windows may be serving a cached icon for the same executable name/path. For diagnosis, **extract a fresh release into an entirely new directory**, then refresh Explorer; do not overwrite an older extraction. If a new folder still shows Java, report a screenshot and the release version. A separate Windows icon-cache rebuild may resolve a persistent stale shell image, but it is not an automatic action performed by WristPorter.
