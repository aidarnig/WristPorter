# WristPorter branding

This file is the single reference for **visual identity and social preview maintenance**.

## Approved identity

The brand uses a blue-to-cyan smartwatch mark with a **WP** monogram and photo symbol on its face. The Windows executable, taskbar and window icon use **only the watch mark**. The JavaFX header displays the full wordmark with a dark `Wrist` on light surfaces and a light `Wrist` on dark surfaces; `Porter` remains blue-to-cyan.

## Canonical and derived assets

- `docs/assets/watch-icon.svg` — standalone watch icon
- `docs/assets/logo-light.svg` / `logo-dark.svg` — full theme-aware wordmarks
- `docs/assets/social-preview.svg` — 2:1, 1280×640, central content with safe margins
- `docs/assets/ui-preview-ru.svg` / `ui-preview-en.svg` — **illustrations**, not actual screenshots
- PNG counterparts and `wristporter.ico` — generated by `ci/render-brand.py`

The `Generate branding assets` workflow regenerates and commits binary exports only when their SVG sources or generator change. The Windows portable packaging uses `docs/assets/wristporter.ico`.

## Set GitHub Social Preview

GitHub's repository Social Preview is not set by merely committing an image. The repository owner must go to **Settings → General → Social preview → Edit → Upload image** and upload the existing **[1280×640 social-preview.png](assets/social-preview.png)** file. This GitHub setting currently cannot be changed by the connected repository-content integration.

## Screenshots in README

GitHub Markdown supports images directly: `![Description](docs/assets/ui-preview-en.png)`. Each language README uses its own localized illustration. Replace these mockups with sanitized, up-to-date screenshots from the *released* UI when available; never commit real device IP addresses, personal photo thumbnails or pairing codes.

## Runtime icon regression (1.1.1)

The UI now reads logo-light.png, logo-dark.png and watch-icon.png directly from packaged classpath resources. The prior runtime vector snapshot was responsible for the incorrect window/taskbar appearance. Windows packaging checks the extracted EXE resource with ci/check-windows-icon.ps1; manual Windows UI verification still applies.
