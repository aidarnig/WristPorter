# WristPorter — быстрый старт

[Русский](QUICK_START.ru.md) · [English](QUICK_START.md)

WristPorter передаёт JPG/PNG с Windows на совместимые часы Wear OS через Wi-Fi. После первичной настройки часов Android-смартфон не требуется.

## Установка и запуск

1. Откройте [GitHub Releases](https://github.com/aidarnig/WristPorter/releases/latest) и скачайте архив WristPorter-...-windows-x64.zip из раздела **Assets**, не **Source code**.
2. Сверьте SHA-256 файла с отдельным файлом *.zip.sha256. Команда PowerShell: `(Get-FileHash .\WristPorter-1.1.2-windows-x64.zip -Algorithm SHA256).Hash`.
3. Полностью распакуйте ZIP, откройте папку WristPorter и запустите WristPorter.exe.
4. Сохраните рядом с EXE папки runtime/, app/ и platform-tools/ — Java и ADB включены в архив. Установщик не нужен.
5. Компьютер и часы должны быть в одной сети Wi-Fi.

## Первоначальное сопряжение

1. На Galaxy Watch 4 Classic включите **Параметры разработчика** через «Настройки → О часах → Сведения о ПО» (несколько нажатий на версию ПО). Подписи меню могут зависеть от версии Wear OS.
2. Включите **Отладку по ADB** и **Беспроводную отладку**.
3. На часах выберите **Сопряжение устройства с помощью кода**. Запишите IP-адрес, порт сопряжения и шестизначный код.
4. В разделе **1 Первое сопряжение** WristPorter введите IP:порт сопряжения и код, нажмите **Сопрячь часы**.
5. На основном экране беспроводной отладки найдите **порт подключения/отладки**. Это **другой порт**, не порт сопряжения.
6. В разделе **2 Подключение** введите IP:порт отладки, нажмите **Подключиться**. При повторном запуске используйте **Обнаружить устройства**.

## Отправка фотографий

1. Нажмите **Добавить файлы**, **Добавить папку** или перетащите JPG/PNG в окно программы.
2. Проверьте очередь и нажмите **Передать на часы**.
3. После копирования WristPorter запросит индексацию изображений для Samsung Gallery.
4. Проверьте Галерею часов. При неудачной индексации используйте **Повторить ошибки**, не дублируя копирование.

## Если что-то не работает

- **Часы не найдены:** проверьте Wi-Fi, беспроводную отладку и актуальный порт подключения. Гостевые сети иногда изолируют устройства.
- **Не проходит сопряжение:** получите новый код и используйте именно порт сопряжения.
- **Старая Java-иконка в Проводнике:** Windows может показывать кешированный значок для уже известного пути EXE. Распакуйте свежий ZIP **в новую папку** и обновите окно Проводника. Значок внутри EXE проверяется при сборке. Подробнее — в [документе о логотипе](BRANDING.md).
- **Не найден ADB:** убедитесь, что в распакованной папке есть platform-tools/adb.exe и две DLL; можно указать его вручную через дополнительные настройки.
- **Фото не появляются:** закрыть и открыть Галерею, проверить результат индексации в WristPorter.
- **Красное предупреждение SmartScreen / «Неизвестный издатель»:** программа пока не подписана доверенным сертификатом; это не является автоматическим доказательством вредоносности, но требует осторожности. Скачивайте только из официального GitHub Releases и проверяйте хэш. Не отключайте защиту Windows. Дополнительно: [Безопасность](SECURITY.md).

После работы отключайте беспроводную отладку на часах. WristPorter не связан официально с Samsung или Google.
