# План развития WristPorter — краткая русская версия

**Основной документ со всеми критериями и зависимостями:** [ROADMAP.md](ROADMAP.md). Эта страница объясняет решение на русском, но **не является вторым источником истины**. Состояние разработки: [STATE.md](STATE.md); стандарт работы для всех чатов и разработчиков: [AGENTS.md](../AGENTS.md).

## Решение

- Не разрабатываем установленное iOS-приложение на текущем этапе. Однако разрешён **веб-интерфейс в Safari**, который обслуживается самим Windows-приложением на локальной сети.
- **WristPorter — экосистема для владельцев Wear OS-часов после перехода с Android на iPhone**, а не только передача фото. Сохраняем рабочую передачу фото в WristPorter Desktop v1.1.2: она должна работать независимо.
- Создаём отдельное **WristPorter Bridge** для Wear OS на Kotlin: соединение с iPhone напрямую по Bluetooth без сервера и компьютера после установки.
- В **том же Windows-приложении** планируем включаемый пользователем режим **Web Upload**: открыть на iPhone Safari локальную страницу по QR, выбрать фото и отправить через Windows + ADB на выбранные часы. Компьютер должен быть включён, отдельной iOS-программы нет.
- В Windows добавим установку/обновление APK (задача W11), диагностику и управление часами. Не делаем два отдельных дистрибутива Windows.
- Максимально реализуем возможности ANCS (уведомления, категории, доступные действия) и AMS (информация о музыке, команды плееру), проверяем дополнительные Bluetooth-сервисы iPhone.
- Особое внимание — **надёжность при блокировке экрана, восстановление связи, энергопотребление, приватность, безопасность, понятный интерфейс RU/EN**.
- Проверенные возможности и гипотезы всегда разделяем. Galaxy Watch4 Classic — основной тестовый образец, но новый Bluetooth-мост **пока на нём не проверен**.

**Два независимых потока:** W0–W12 для Bluetooth-моста и W13–W16 для браузерной передачи через Windows. Они могут развиваться параллельно в отдельных чатах. [Технический план Web Upload](LOCAL_WEB_PORTAL.md) и [решение ADR-0004](adr/0004-one-desktop-optional-lan-portal.md).

**Сначала W0 (для Bluetooth-моста):** никакого сброса часов и голословных обещаний о совместимости. После W2 задачи по уведомлениям и музыке можно вести параллельно в разных чатах, закрепляя изменения за отдельными GitHub Issues.

## Что без приложения на iPhone не обещаем

Произвольные ответы на сообщения; **прямую** передачу фотографий с iPhone на часы **без Windows**; синхронизацию Apple Health/Samsung Health; контакты iPhone; полноценную замену Galaxy Wearable и первоначальную настройку часов; передачу звука телефонного вызова в динамик часов; полный контроль iOS. Подробная граница функций — [BRIDGE_CAPABILITIES.md](BRIDGE_CAPABILITIES.md).

## Как переключаться между чатами

Новый чат должен открыть [AGENTS.md](../AGENTS.md), затем [STATE.md](STATE.md), затем Issue конкретной задачи и связанные документы. В конце каждой задачи фиксируются PR, проверки, оставшиеся проблемы и следующий шаг **в GitHub, а не только в переписке**. История чатов — вспомогательный материал, не единственный источник контекста.

Видео/GIF пока остаётся отдельной отложенной задачей [#10](https://github.com/aidarnig/WristPorter/issues/10).
